V10 STRAFE TEST V2

Extract whole ZIP to a fresh folder. Close DayZ, keep Steam running, run Launch-Movement-Test.cmd.

Built directly from original v10. Pure standing A/D abrupt reversals request very slow movement (gait 0.15). Repeated reversals keep it slow. Holding one direction for more than 0.30s starts an 0.08s smooth recovery. Releasing all movement lets v10 stopping finish. Short release gaps up to 0.18s still detect the opposite direction. Applies with Shift too; walking mode, crouch and forward/back movement retain v10 behavior. No angle override, frozen pose, command restart or signed momentum from previous tests.

Native DayZ compilation and actual velocity/animation appearance must be tested in-game. Controller mocks do not simulate native blending or physics. V10 remains the baseline.
